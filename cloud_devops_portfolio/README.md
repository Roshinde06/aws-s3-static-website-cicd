# Cloud & DevOps Portfolio (HTML, CSS, JavaScript)

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive styles
- `script.js` — mobile menu and current footer year

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Edit the files in VS Code and refresh the browser to see changes.

## Personalize before publishing
1. In `index.html`, replace `your.email@example.com` with your professional email.
2. Replace the generic LinkedIn and GitHub URLs with your profile URLs.
3. Add the exact GitHub repository URLs to each project card.
4. Only list tools and projects you can explain in an interview. Mark unfinished work as "in progress" or "planned".
5. Check the page on mobile and desktop.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `cloud-devops-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Select the main branch and root folder, then save.
5. Follow the Pages URL shown by GitHub after deployment.

This is a static website; no server or build step is required.
